# Asset-Maintenance Reference Cartridge

This directory and `src/cartridges/asset-maintenance` preserve a completed mock
implementation of an industrial fleet-maintenance prompt.

It demonstrates:

- telemetry and fault fixtures;
- quality/freshness checks;
- deterministic rule-based recommendations;
- evidence citations;
- human-confirmed work orders;
- an in-memory audit/offline demo;
- QA, review, presentation, and fallback artifacts.

It does **not** represent an official Caterpillar problem statement, competition ruling,
submission, measured customer outcome, or production system. The historical worker briefs
and evidence refer to the repository layout that existed when the mock was built.

Use it as an example cartridge. After the real reveal, either adapt it because the problem
genuinely matches or leave it untouched and create a new cartridge.
